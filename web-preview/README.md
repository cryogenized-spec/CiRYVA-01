# CiRYVA browser preview

An installable, local-only interface preview ported from the current Elara visual system. Underlying CSS sources: Elara `layout.css`, `app.css`, `portrait-banner.css`, `conversation-surface.css`, and `composer-layout.css`, followed by scoped CiRYVA overrides. No live AI provider calls, paid requests, or Android-native APIs. Browser chat is stored locally. This preview is independent from the Android Release-1 integration gate.
